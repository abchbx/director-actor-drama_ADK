# Phase 24-02: Android ActorInfo 扩展 + cast_change WS 事件 + 演员面板 UI 改造

**Plan:** 24-02
**Phase:** 24 (场景级演员调度)
**Requirements:** CAST-05, CAST-06
**Depends on:** 24-01 (后端 scene_cast 机制)
**Estimated tasks:** 7

## Goal

在 Android 客户端扩展 `ActorInfo` 数据模型，添加 `onStage` 字段；处理 `cast_change` WS 事件实时更新演员上下场状态；改造演员面板 UI 区分在场/待机演员；实现导演手动选角交互。

## Success Criteria

1. `ActorInfo` 新增 `onStage: Boolean = true` 字段，默认 `true` 向后兼容
2. `mergeCastWithStatus()` 从 `/drama/cast/status` 响应中读取 `scene_cast` 字段填充 `onStage`
3. `cast_change` WS 事件实时更新演员 `onStage` 状态，无需全量刷新
4. `ActorDrawerContent` 区分在场（高亮）和待机（灰显）演员，分两组显示
5. `ActorCard` 添加 toggle 开关，点击切换演员上下场
6. 切换上下场调用 `POST /drama/chat` 发送 `/cast 演员1,演员2` 命令
7. `ChatInputBar` 的 @mention 芯片区分在场/待机演员视觉状态

### Task 4: DramaDetailViewModel 处理 cast_change 事件
**File:** `android/app/src/main/java/com/drama/app/ui/screens/dramadetail/DramaDetailViewModel.kt`
**Requirements:** CAST-05
**Changes:**
- `handleWsEvent()` 添加 `cast_change` 事件处理（在 `cast_update` 分支附近）：
  ```kotlin
  "cast_change" -> {
      val sceneCast = event.data["scene_cast"]?.let { elem ->
          (elem as? kotlinx.serialization.json.JsonArray)?.mapNotNull {
              it.jsonPrimitive.contentOrNull
          }
      }
      if (sceneCast != null) {
          // 增量更新 onStage 状态
          _uiState.update { state ->
              state.copy(actors = state.actors.map { actor ->
                  actor.copy(onStage = sceneCast.isEmpty() || actor.name in sceneCast)
              })
          }
      } else {
          // scene_cast 为 null，全员上场
          _uiState.update { state ->
              state.copy(actors = state.actors.map { it.copy(onStage = true) })
          }
      }
  }
  ```
- 不调用 `preloadActorPanel()`（避免全量刷新），直接增量更新 onStage

```kotlin
fun toggleActorOnStage(actorName: String) {
    val currentCast = _uiState.value.actors
        .filter { it.onStage }
        .map { it.name }
        .toMutableList()

    // 切换：在场 → 移除，待机 → 添加
    if (actorName in currentCast) {
        currentCast.remove(actorName)
    } else {
        currentCast.add(actorName)
    }

    // 校验至少一人
    if (currentCast.isEmpty()) {
        // 显示错误提示
        return
    }

    viewModelScope.launch {
        dramaRepository.setSceneCast(currentCast)
            .onSuccess { /* WS cast_change 事件会自动更新 UI */ }
            .onFailure { /* 回滚 UI 状态 */ }
    }
}
```

**乐观更新策略：** 先更新本地 UI（立即反馈），WS `cast_change` 事件到达后确认。如果 REST 失败则回滚。

## Risks & Mitigations

| Risk | Severity | Mitigation |
|------|----------|------------|
| REST 调用失败导致 UI 与后端不一致 | MEDIUM | 乐观更新 + 失败回滚 + WS 事件最终一致 |
| 待机演员被 @mention 后 LLM 不知如何处理 | LOW | @mention 路由到 /speak，LLM 可通过 scene_cast 感知 |
| 演员面板分组后列表过长 | LOW | 待机组可折叠 |
| toggle 快速点击导致重复 API 调用 | LOW | debounce 300ms + isProcessing 锁 |
