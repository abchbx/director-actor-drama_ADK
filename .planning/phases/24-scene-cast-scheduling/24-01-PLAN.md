# Phase 24-01: 后端 scene_cast 机制 + set_scene_cast 工具 + next_scene/actor_speak_batch 改造

**Plan:** 24-01
**Phase:** 24 (场景级演员调度)
**Requirements:** CAST-01, CAST-02, CAST-03, CAST-04
**Depends on:** Phase 22 (群聊模式), Phase 23 (技术债务治理)
**Estimated tasks:** 8

## Goal

在后端引入 `scene_cast` 机制：state 新增 `scene_cast` 字段，新增 `set_scene_cast` 导演工具，改造 `next_scene()` 和 `actor_speak_batch()` 使用 scene_cast 过滤，新增 `cast_change` WS 事件。

## Success Criteria

1. `state["scene_cast"]` 字段存在，默认值 `None`（表示全员上场），迁移逻辑在 `load_progress()` 中
2. `set_scene_cast(cast)` 工具校验非空 + 演员存在性，自动包含用户主角，返回 scene_cast + standby 列表
3. `next_scene()` 返回 `scene_cast` 和 `standby` 字段，`actors_available` 改为仅上场演员
4. `actor_speak_batch()` 跳过不在 scene_cast 中的待机演员，返回 skip 信息
5. `cast_change` WS 事件在 `set_scene_cast` 调用时推送，包含 scene_cast + standby 列表
6. `next_scene()` 场景推进时重置 scene_cast 为所有 AI 演员名（默认行为）
7. `/drama/cast/status` REST 端点返回 `scene_cast` 字段，供 Android 客户端查询
8. 后端单元测试覆盖：空 cast 校验、无效演员、待机跳过、迁移兼容

## Task Breakdown

### Task 1: state_manager 新增 scene_cast 字段初始化 + 迁移
**File:** `app/state_manager.py`
**Requirements:** CAST-01
**Changes:**
- `init_drama_state()` (line ~578): 添加 `state["scene_cast"] = None`
- `load_progress()` (line ~934-1001): 添加 `state.setdefault("scene_cast", None)`
- 新增辅助函数 `get_scene_cast(state) -> list[str]`：
  - 读取 `state.get("scene_cast")`
  - 若 `None`，返回所有非用户主角演员名（默认全员上场）
  - 若非 `None`，返回原值
- 新增辅助函数 `get_ai_actors(state) -> list[str]`：
  - 返回 `[n for n, d in state.get("actors", {}).items() if not d.get("is_user_protagonist")]`

**Pitfall guard:** `None` vs `[]` 语义区分 — `None` = 未设置（全员上场），`[]` = 明确为空（不应出现，set_scene_cast 校验阻止）

### Task 2: set_scene_cast 工具函数
**File:** `app/tools.py`
**Requirements:** CAST-02
**Changes:**
- 新增 `set_scene_cast(cast: list[str], tool_context: ToolContext) -> dict`
- 遵循 `steer_drama` 模式：`_get_state()` → 参数校验 → 修改 state → `_set_state()` → 返回 dict
- 校验逻辑：
  1. `cast` 不能为空 → 返回 error
  2. 演员名必须存在于 `state["actors"]` → 返回 error + 无效名列表
  3. 自动包含用户主角（`is_user_protagonist=True` 的演员始终在场）
  4. 去重保序
- 返回值：
  ```python
  {
      "status": "success",
      "scene_cast": full_cast,     # 包含用户主角
      "standby": standby_list,     # 不在 cast 中的 AI 演员
      "message": "🎭 场景卡司已更新\n上场：...\n待机：...",
  }
  ```
- 在 `agent.py` 的 `_improv_director` tools 列表中注册

### Task 3: next_scene() 改造
**File:** `app/tools.py`
**Requirements:** CAST-03


### Task 4: actor_speak_batch() 改造
**File:** `app/tools.py`
**Requirements:** CAST-03
**Changes:**
- `actor_speak_batch()` (line ~569): Phase 1 准备阶段添加 scene_cast 过滤
- 在遍历 `actors` 列表时，检查 `scene_cast`：
  ```python
  scene_cast = state.get("scene_cast")  # None = 不限制（旧存档兼容）
  for entry in actors:
      actor_name = entry.get("actor_name", "")
  ```

- 注意：待机演员不参与 A2A 调用，不消耗 token

## Risks & Mitigations

| Risk | Severity | Mitigation |
|------|----------|------------|
| scene_cast 为空导致无人发言 | HIGH | set_scene_cast 校验非空；next_scene 默认重置为全员 |
| 旧存档 scene_cast 缺失 | MEDIUM | None = 全员上场语义；load_progress 迁移 |
| next_scene 重置导致导演选角丢失 | MEDIUM | 文档说明：导演需在 /next 后重新选角；未来可考虑 cast 参数 |
| actor_speak_batch 跳过逻辑影响 LLM 决策 | LOW | LLM 传入的 actors 列表本身由 scene_cast 过滤后的 actors_available 决定 |
